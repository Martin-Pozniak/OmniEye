# OmniEye UI

**OmniEye UI** is a powerful open-source interface for Open Source Intelligence (OSINT) gathering and analysis. It enables users to input preliminary subject details—such as name, location, or occupation—and leverages public data sources and third-party OSINT tools to compile a detailed profile and generate a **privacy exposure score** based on the personal information discovered.

Whether you're an ethical hacker, researcher, journalist, or privacy advocate, OmniEye provides an intuitive front-end for conducting structured investigations using publicly accessible data.

## 🔍 Key Features

- **Subject-driven OSINT workflows**: Enter partial identity information to initiate deep public data scans.
- **Integrated data collectors**: Uses open-source tools and web scraping to aggregate publicly available content.
- **Privacy exposure scoring**: Generates a ranked score reflecting how much personal data is publicly accessible.
- **Interactive visualizations**: Easily analyze, compare, and explore collected intelligence.
- **Modular and extensible**: Designed to integrate new sources and tools over time.
- **Community-focused and transparent**: Fully open-source and welcoming to contributors.
